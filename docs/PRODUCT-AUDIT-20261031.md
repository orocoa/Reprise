# Reprise 目标与技术审查 · 2026-10-31

结论：Reprise 已具备“新手通过 Agent 留稿、凭画面找旧稿、取出副本继续修改”的完整主流程。核心存储、只读 Git 和恢复校验有清楚的边界，不支持把整个项目推倒重写。需要处理的复杂度主要在前端异步流程、版本类型判断、预览资源生命周期和历史说明。0.8.5 对这些边界作了集中收口；它仍是需要主动留稿的本地工具，不保证任意历史网页都可运行。

## 从目标检查

| 原始目标 | 当前实现与判断 |
| --- | --- |
| 新手能在改网页时留下版本 | Agent 复用当前项目，保存目录确切内容，自动名称可用；未变化沿用原稿。截图偏好按项目问一次并保存。打开工具不自动留稿，未记录内容无法事后恢复。符合主动留稿目标。 |
| 快速找到之前的网页 | 时间、名称、搜索、收藏、画面列表与真实版本关系共用准确版本身份；缺图明确显示。详细资料按需加载并有缓存边界。符合已保存、已加载历史的查找目标。超大历史仍有加载和渲染成本。 |
| 取回旧版继续做 | 恢复到新的外部目录，逐对象/字节读回，提供继续修改指令；原项目保留。文件恢复与网页运行分别报告。符合目标。 |
| 删除不需要的版本 | 普通留稿可删除保存状态和所选受管附件；Git/归档只移除 Reprise 本机条目与附件，源历史保留。预检、显式确认、共同引用核验和结果回执保留。符合工具实际拥有的数据边界。 |
| 减少磁盘与内存负担 | 相同文件内容共享存储；生成依赖经验证后可释放。内存通过停止对应预览/服务处理，不能用磁盘数字代替。0.8.5 增加预览窗直接停止入口，并取消静态预览就绪后的持续进程表扫描。符合具体资源管理目标，未承诺系统级清理。 |

## 技术质量

可保留的部分：Python 标准库核心、CLI/HTTP 共用服务层，版本对象、运行副本、截图证据和恢复回执分开。导入源不执行 Git 写入、hooks/filters 或原目录安装。截图绑定完整 SHA；版本删除先验证保留内容，未知引用和损坏记录阻止回收。为了减少代码量而删除这些校验，会损害版本管理器最重要的数据可靠性。

实际技术债及处理：

- 版本类型与可操作性曾分散在多个前端分支。现在后端提供同一份版本动作契约，预览、删除选择与计划解释使用一致含义。
- 运行预览和多个弹窗曾共享零散状态。现在由统一控制器约束版本、配方散列、任务和弹窗代次，防止重复启动与迟到结果覆盖。
- 恢复位置曾混合候选生成与保护校验。现在显式选择来源关联的外部根，执行时仍复核，不覆盖现有目录。
- 静态服务器就绪后仍保留高频子进程观察，造成可避免的空闲负载。受信任静态服务器不派生子进程，现在停止持续观察；运行状态与停止仍按需刷新核验。执行项目命令的预览保留完整跟踪。
- 停止后的进程对象/观察器曾持续留在服务内存映射。现在在确认停止后释放这些句柄；磁盘记录保留供校验和重试。
- Skill 与部分中英删除说明仍引用旧候选范围，且未直接路由“停止预览”。现已区分进程、生成依赖、保存状态和只读历史条目的四种操作，说明 CLI 联合内容删除与界面附件删除的范围差异。

前端继续使用有共享状态的普通 JavaScript，备份、迁移和旧归档兼容模块较多，维护成本高于最初的三步留稿工具。但现有资源有真实兼容用途，默认界面与发行包已按活动入口收口；本次没有观察到必须引入框架或重写内容库才能解决的问题。保留历史源码不等于让它们全部进入运行入口。

## 负载实测与验证口径

本机同一脚本、两个合成静态预览、各五秒的空闲采样：修复前记录到 36 次全用户进程表扫描、两个持续观察线程，父进程及其观察辅助进程合计约 1.342 CPU 秒；修复后为零次扫描、零个持续观察线程，约 0.000035 CPU 秒。它证明这条空闲监控路径被消除；短采样不代表其他机器、命令型应用或整台电脑的性能，也不测量实际释放的 RAM。

专项覆盖静态 HTTP、身份核验后停止、重载管理器停止、重复停止、命令型子进程观察、预览停止失败与迟到结果。Ego Lite 使用独立合成项目检查中英文运行/停止、删除范围、实际删除及源文件不变；390px 页面无横向溢出。完整回归、安装包与平台结果以 [0.8.5 验证说明](VALIDATION-0.8.5.md) 和 GitHub CI 实际结果为准，不能用旧构建结果代替最终构建。

## 发布判断与保留限制

上述主流程的功能边界完整，可以作为本地网页版本管理器发布；发布仍以最终回归、安装物、公开下载与本地安装校验完成为准。“全部功能可实现”指文档声明范围内的操作，不指所有框架、所有外部服务或任意历史版本必然运行。

没有自动留稿、云同步、全盘清理或通用 RAM 优化。截图不是数据库/外部依赖备份，同盘历史不是独立备份。删除可能需要临时重打包空间；附件清理部分失败会保留回执并报告未完成。历史图加载有边界，尚无多 TB 删除或数万节点完整界面压力结论。原始 Git 标题、作者与用户提供内容不会因为切换界面语言而被自动改写。
