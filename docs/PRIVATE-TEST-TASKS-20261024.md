# 倒带 / Reprise：一页试用任务

2026-10-24 · 0.8 本地候选。未招募、未邀请、未发布；以下不是已取得的结果。本页是本轮唯一试用方案；[English](PRIVATE-TEST-TASKS.en-20261024.md) 是同一方案的翻译。

**找 5–8 位正在用 AI agent 或编辑器做本地网页、近期确实想找旧稿的人，定性观察一条任务：保存两稿 → 凭画面找目标稿 → 取回继续改。** 人数是投入边界，不是统计证明。这轮不扩平台、通用功能或宣传渠道。

## 给参与者

> 用你正在修改的一份本地网页，保存现在这一稿和画面。做一处本来就想改的调整，再保存第二稿和画面。从两稿画面里选出想回去继续试的一张；稍后只凭这张图在倒带里找回它，取出副本，再改一次。现在的项目也要保留。

> Save a draft of a local webpage you are working on, including its screenshot. Make a change you already wanted to try, then save a second draft and its screenshot. Choose the earlier appearance you want to return to. Use that image to find the draft in Reprise, retrieve a copy, and edit it again. Keep your current project too.

使用参与者同意试用的无敏感网页副本，保留原项目。开始前说明候选包和环境限制；无法使用真实任务时标为练习，不计为真实任务验证。“打开”不应保存或导入当前目录。Skill 选择按客户端实际能力，不承诺统一 `@` 别名。

## 观察者只做这些

| 环节 | 观察与记录 |
| --- | --- |
| 原方法 | 先问最近一次找稿经历。有旧历史时看对方用原方法找回一次；没有就不编造困难的前测。没有实际任务记“不匹配”。 |
| 接入 | 包版本、设备、客户端、安装与首次打开用时和阻塞，和后面的任务用时分开。 |
| 两次保存 | 两稿来自正确项目，文件与各自画面分别完成。缺图就记缺图，不借别稿画面补齐。 |
| 凭图找稿 | 对方先选目标画面；随后只给图，不透露稿名、时间、序号或目标卡片。正常界面信息照常显示。 |
| 取回继续改 | 参与者找到副本并修改。非开发者无需读 SHA / Git；观察者核验画面、版本和取回文件对应，当前项目保持原样。 |
| 后续机会 | 14 天不提醒保存；记录有无同类任务、是否主动再用、是否自然发生找稿。首次两稿是操作检查，长期价值以自然任务为准；无机会和失访分别记。 |

提供同一份正常说明，不指按钮、不代操作；必要帮助和临时修复原样记录，不算独立完成。维护者自测、合成演示、照教程跟做不能计为外部用户独立完成真实任务。只存到文件、没有图，不算本轮视觉任务完成。

每人一行匿名记录：`任务与原方法 / 环境与包版本 / 接入阻塞 / 两稿文件及截图结果 / 选稿是否正确 / 取回与继续修改 / 观察者安全核验 / 独立或受助 / 卡点与用时 / 后续机会与主动复用 / 具体收益或不用理由`。不收集私人路径、原文件、密钥或未经匿名化日志。报告实际人数、帮助和未知项，不只报成功率。

## 决策与停止

- 误存无关目录、覆盖当前项目、取回错稿、损坏或错图报成功：立即暂停受影响路径，保留证据，修复再测。
- 入门或框架反复阻塞：暂停扩大邀请，集中修正；静态样本成功不能抵销真实项目失败。
- 有人独立完成并说清相对原方法少了哪一步，值得继续观察；有机会时无人提醒地复用，是更强信号。
- 观察期后最多做一轮针对已观察阻塞的集中修正。有机会的人仍不复用或认为原方法更省事：保留个人工具，停止泛化扩展。招募不足、没有下一次任务或失访，均不能补算成功。

只验证“少步骤、画面对应准确文件、取出可继续修改的新副本”是否值得安装和主动保存，不宣称独有技术。Star、收藏和观看是传播兴趣，不能替代正确完成或复用。开源分享与定向小试合理；广泛推广仍缺证据。

原任务 A 的文本恢复、B 的 SHA / 双侧比较可留作工程检查；原任务 C“旧目录归并、删除候选和空间数字”**明确排除本轮试用**，不选择或执行删除。旧任务原文完整保留于维护者本机评审档案，参与者无须访问。短介绍、演示分镜和证据边界见[分享简报](SHARING-BRIEF.md)。
