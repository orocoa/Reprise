# Reprise 白纸线框

冻结基准：2026-10-08，用户确认竖线向右并入真实右边框后的版本。采用这套视觉时读取 [视觉规范](references/design-system.md) 与 [动画规范](references/motion.md)，查看 `assets/visual-reference/` 的真实截图与动画；精确参数在 `references/computed-tokens.json`。不要从后来改变过的 Reprise 界面替代这份基准。

## 保留识别特征

白纸、黑色文字、2px 主线与 1px 灰色次线，直角、平整界面、清楚的留白和文字层级。框架居中，顶栏横线跨窗口，品牌从框架左边缘起笔。全宽目录进入详情时收向左栏；左栏与正文约 1:3，窄容器改为上下排列。全宽列表名称居中，详情目录左对齐。hover 直接黑白反转，选中以黑色文字、字重和已有线框表达。相关内容原位 ＋/− 展开，保留返回和空状态。

线框按真实起终点直接移动；620ms `cubic-bezier(.22,.68,.18,1)`，到位后约 200ms 呈现内容并调整线重。必要时允许并入真实边框：内部竖线进入无内部栏的管理式全宽页面时向右推入实际右框；两端都没有内部竖线时不生成它。横线避免无必要的多线汇合。连续点击承接当前画面，覆盖层清理与减少动态效果沿用冻结实现。

## 在新项目中使用

`assets/starter/` 包含通用内容的独立演示、原样 CSS 和运动引擎。先检查现有组件结构与用户要求的采用范围，再替换业务文案、图片、数据和选择器；保留视觉关系与运动阶段。阅读其中 `INTEGRATION.md` 后接入新技术栈。

原 CSS 存在多轮叠加，按最终计算值和真实截图判断效果。可以按新项目组件整理实现，但不要因看到早期规则而把最后确认的视觉改回去。采用实际框架公式，不能硬编码参考视口坐标；不要复制原项目标题、SHA、本地路径、服务地址或 Git 操作。

检查实际起终点、线重层级、内容最终位置、hover/选中、窄屏、必要并框、快速切换与减少动态效果。此技能用于复现明确请求的视觉，不自动改造无关项目或其模型设置。
