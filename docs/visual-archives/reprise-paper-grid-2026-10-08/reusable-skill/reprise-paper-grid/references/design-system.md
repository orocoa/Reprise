# Reprise Paper Grid · 白纸线框

冻结日期：2026-10-08。此档案保存用户最终确认的 Reprise 视觉、排版与动画，包含竖分隔线向右并入真实边框的最后一次修复。以后 Reprise 更换视觉时，继续保留本档案，新增版本另建目录。

## 基准与参考

先查看 `../assets/visual-reference/` 的真实截图与动画，阅读本文件、[动画规范](motion.md) 和 [实际样式参数](computed-tokens.json)。`../assets/starter/` 提供通用内容的交互示例、原样 CSS 和动画引擎，不含原项目数据。原 CSS 保留叠加顺序，以最后生效的规则与实际计算值判断视觉。

这套视觉可以复用为资料库、版本浏览器、作品集、档案管理或工具界面。项目名、业务内容、图片和操作可以替换；排版关系、线条层级、留白和动画节奏是保留对象。参考内容及截图属于此本地档案，不等于新项目的内容素材。

## 视觉识别

白纸、黑色文字、连续的横竖线与大量留白组成界面。线条建立信息分区和阅读顺序，文字与线框承担状态反馈。页面由一个居中的框架组织；品牌从框架左边缘起笔，顶栏横线横跨窗口，内容区域的左右边框保持清楚。

当前品牌处理是纯文字字标，24px、500 字重、1.3 行高，无图形徽标。中英切换使用 `[ 中 / EN ]` 的轻量文字结构。搜索、展开、收起、跳转以细线图标、＋/− 和 ↗ 表达，图标约 1em。

保留直角、平整纸面、黑白反转 hover、简洁文字按钮与细边框按钮。当前体系没有渐变、装饰投影、圆角卡片或大面积彩色高亮；复用时沿用这些已确认的选择。

## 色彩与线条

| 用途 | 最终值 | 使用方式 |
| --- | --- | --- |
| 纸面 | `#fff` | 页面和内容背景 |
| 正文 | `#111` | 阅读内容 |
| 字标、选中项、主线 | `#000` | 主状态与结构 |
| 次要文字 | `#666` | 未选中行、补充说明 |
| 弱元信息 | `#888` | 日期等次级内容 |
| 次线 | `#c8c8c8` | 同一区域中的行分隔 |
| 主线宽 | `2px` | 页面框架、功能区域、主横线、内部竖分隔线 |
| 次线宽 | `1px` | 历史行、文件行和区域内部条目 |

主线区分功能，次线区分条目。不要把所有线都变为相同粗细或灰度，也不要将多个条目包成一张独立卡片。

## 框架与留白

| 项目 | 冻结规则 |
| --- | --- |
| 基础网格 | `8px` |
| 常规内容内边距 | `32px`，窄屏按冻结 CSS 变为 `24px` / `20px` |
| 页面最大宽度 | `1600px` |
| 外侧留白 | `clamp(12px, calc(12.5vw - 80px), 160px)` |
| 页面宽度 | `calc(100% - 外侧留白 × 2)`，水平居中 |
| 桌面顶栏 | `80px` 起，允许内容换行 |
| 当前 Git 行 | `96px` |
| 搜索行 | `56px` |
| 历史列表全宽行 | 最小 `80px`，上下 `24px` |
| 详情列 | 左侧 `minmax(calc(224px + 内边距 × 2), 1fr)`，右侧 `minmax(0, 3fr)` |

桌面详情大致是 1:3 的左右关系，左栏有最小宽度。它与全宽列表是同一目录的两个布局状态。左栏目录随正文滚动保持可用，历史列表在自己的区域内滚动。页面外框、目录边界和正文起笔位置共同组成稳定的阅读网格。

在实际记录的 `1350 × 728` 视口下，页面框架约 `1161.25px`，详情左栏约 `289.31px`。这些是校验参考值，跨项目使用时应沿用公式，不写死此视口的坐标。

容器宽度不超过 `760px` 时详情改为上下排列，内部竖线变成水平分隔；资源行也折成多行。`1000px` 容器规则和 `700px` 视口规则进一步调整操作、顶栏与字号。窄屏仍保留当前选项、空状态与返回路径。

## 字体与层级

字体栈为 `Inter, -apple-system, system-ui, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`；等宽内容使用 `ui-monospace, SFMono-Regular, monospace`。源界面没有打包字体文件，跨平台会使用相应回退字体；截图保存了本次实际显示效果。

| 内容 | 桌面参考 |
| --- | --- |
| 字标 | `24px / 31.2px`，500 |
| 导航 | `14px / 23.1px`，选中 600 |
| 全宽列表标题 | `16px / 24px`，600，居中 |
| 左栏列表标题 | `15px / 24px`，未选中 400、选中 500，左对齐 |
| 详情标题 | `32px / 40px`，600 |
| 内容摘要 | `16px / 27.2px`，500 |
| 正文基础 | `14px`，约 1.65 行高 |
| 搜索、补充说明、轻按钮 | `12–13px` |
| 日期 | `11px`，次要颜色 |

字号和字重建立明确层级。正文保持易读的行长和行距；标题不依靠装饰背景获得强调。

## 页面与组件

### 全宽列表

当前入口位于最上方，随后是搜索，再是水平展开的历史行。历史行只显示名称并居中；日期保留在详情里。搜索也居中，图标紧邻文本。此状态没有内部竖分隔线，两側外框持续存在。

### 列表与详情

目录收向左栏，目录标题和搜索转为左对齐。右侧包含明确的返回版本列表入口、日期和类型、标题与轻操作、变化说明、对照入口、预览选项、媒体画面与底部说明。相关详情优先原位展开，保留起始上下文。

### 当前 Git

沿用同一左栏。右侧使用标题区、状态摘要、文件行和操作区；结构仍由横线和文字层级组织。列表、正文和操作的边缘与同一网格对齐。

### 管理页

全宽标题区，以下使用行式资源排版。条目包含名称、状态、容量与文字操作；主边界使用黑线，内部行使用灰线。AI 区域和 Git 区域沿用同一排版秩序。管理页没有内部竖分隔线。

### 交互状态

hover 使用直接的黑底白字反转，没有延迟变色。选中项的文本变黑、加粗；导航选中主要由文字状态表达。键盘焦点有清楚的线或下划线。预览选项通过 ＋/− 原位展开，选项保持可见，选择后收起；缺少内容时保留入口并给出空状态。

对比视图使用相同横线对齐两边的信息区，窄屏上下排列。图片保持自身比例；媒体缩放和原文件入口沿用轻量文字操作。数据、截图和媒体必须绑定它们真实所属的版本，不以另一版本的资源补位。

## 动画的识别特征

线框先移动到布局终点，文字与内容随后自然出现。默认 `620ms`，缓动 `cubic-bezier(.22,.68,.18,1)`，再用约 `200ms` 呈现内容。目录文字的呈现为 `180ms`；预览展开为 `420ms`。完整行为见 [MOTION.md](motion.md)。

用户最终认可的合并规则是：必要时可以并入真实边框。详情到管理的内部竖线向右推进，与最右侧边框自然收拢；全宽列表到管理不生成不存在的内部竖线。横线直接过渡，避免多根线无必要地挤到同一个终点。
