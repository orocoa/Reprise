# Reprise 0.8.2 验证范围

2026-10-26。本版沿用 [0.8.1 的主流程与结构收敛](VALIDATION-0.8.1.md)，修复同一网页同时登记为留稿项目和 Git 历史时，名称与路径相同而用途不明确的问题。

项目选择器明确标注「网页留稿」「Git 历史 · 只读」「历史存档 · 只读」。用途来自项目身份，不从名称或路径猜测；无类型的旧 Git 记录仍按原兼容语义显示只读历史。默认 Agent 摘要仍不输出路径。

新增真实浏览器场景同时注册同名同路径的两个项目，按用途选中后核对保存按钮、空留稿与真实 Git 历史、中英文及手机布局，并核对源目录和 Git 文件没有改变。缩略图、固定紧凑关系图、准确版本媒体和新副本恢复沿用同一实现。

完整回归与安装包身份以正式发布说明、对应 CI 和附件校验清单为准。跨平台跳过范围、新机器环境、其他客户端原生接入和真实设计师采用仍按 0.8.1 的边界分别记录。
