# 本地数据与隐私

Reprise 的保存版本、指纹计算、去重、比较、恢复和整理校验在本机执行，不调用模型、不自动上传、不上报遥测。只处理用户明确加入的项目，没有后台全盘扫描。普通文件夹无需初始化 Git；当前实现使用 Reprise 自有的 Git 对象库，所以仍需安装 Git 程序。

首次保存需要读取所选文件的字节计算指纹；后续通过元数据签名筛选变化的文件。文件级去重比较完全相同的内容，不理解文章主题、不做 OCR、向量索引或语义分类。普通文件夹的排除规则在遍历前过滤，排除的目录不下钻，`.git` 自动排除。保存结果明确列出排除项，不能把排除项说成已备份。

主动请求版本完整性检查时，Reprise 会读取所选版本的清单与已存内容来重算指纹，不读取原文件夹、不请求模型，也不产生额外恢复副本。存储账本只读取当前数据目录的文件元数据，不读取正文，不跟随符号链接或外部源目录。检查任务与摘要会保存在本机；内容检查通过不能当成独立备份或实际恢复验证通过。

持久化索引包含相对路径、类型、大小、权限、时间、设备/inode、指纹、版本引用和排除项。版本库还保存原始文件内容。项目登记含本机绝对路径；校验回执和恢复目录也保存到本机。默认 CLI `projects` 返回名称/标识/类型，`review` 返回校验摘要；`--details` 才展开完整清单。路径和哈希同样可能是敏感信息。

macOS 默认位置为 `~/Library/Application Support/Reprise`；其他平台使用 XDG 数据目录，可通过 `REPRISE_DATA` 或 `--data` 改变。执行 `privacy` 或在界面打开「本地数据与隐私」可查看当前实际位置和范围。数据根目录使用账户私有权限，版本库未加密。这不能阻止拥有同一账户文件权限的程序访问，也不是操作系统级沙箱。

通过 Codex 等 AI 代理调用 Skill 时，命令输出、文件清单和代理主动打开的文件可能进入模型上下文，适用该代理的数据政策。Reprise 无法约束宿主代理的全部文件权限或数据处理方式。因此不能承诺“用 Skill 时所有数据绝不离开设备”。直接在本机工作台使用基础版本功能，不需要调用 AI 代理。

可选「AI 建议」由用户主动触发，发往用户配置的服务；可能包含提交标题、父提交、变化文件名、最多 300 条路径及最多 6 个有界构建清单。界面在发送前说明范围，AI 配置与基础功能分开；保存、去重、整理和恢复不读取 AI 配置来发送请求。项目运行配方中的联网与命令执行是另一项明确操作，不属于保存或去重。

排除路径或移除登记不抹去旧版本中的内容。版本库、索引、回执、展开恢复副本和失败诊断持续保留。卸载 Skill 不删除用户数据。当前整理功能生成经过恢复读回验证的候选清单，用户勾选后保存为待执行选择，不自动删除副本、版本或对象；实际移除需另外明确执行。逻辑重复字节不等于文件系统实际可回收块，展开验证副本也会增加占用。

0.7.0 的「整理版本」是另外明确执行的操作：先列出所选版本及损失、整个库的共同引用和独占未压缩内容，再确认删除。它只删除所选受管历史及已无引用的对象，保留源目录、恢复副本、截图、日志、运行环境和孤立诊断；回执与选择路径仍留在本机。环境释放另外确认，只移除实际重建成功并再次核验的登记生成目录。两者不是安全擦除，不保证文件系统快照、备份或其他副本已消失。

运行配方的安装、构建和启动命令以当前账户执行，可能联网或读写宿主资源；`network:local` 仅限制浏览器采集，并不沙箱化包管理器。保存源码和锁文件不等于未来包源永久可用；已验证重建有时间和工具范围。

恢复校验明确范围：普通文件夹验证文件字节、路径、权限、修改时间、扩展属性、安全相对链接和空目录；ACL、文件系统标志、所有者、排除项、完整依赖与程序运行效果未被完整验证。具有未覆盖属性、变化中的内容、Git 跟踪文件、Reprise 已登记运行目录会保留或阻止选择。保护范围在校验开始时固定，后续只增加。旧档案按其原始格式恢复嵌套 `.git` 与所记录元数据，分别报告原始 SHA、视图 SHA 和元数据警告。

Skill 包包含来源提交、源码树摘要和逐文件校验清单，`doctor` 可检测文件缺失或被修改。哈希提供完整性核对，不是作者身份签名，也不证明源码绝无缺陷。当前本地包包含已注明的未提交源码；不把本地验证等同于正式发布或独立安全审计。
