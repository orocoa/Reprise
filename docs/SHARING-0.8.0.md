# Reprise 0.8.0：分享材料 / Sharing copy

下列第三方文案为待发布草稿，未自动发帖、私信或邀请；GitHub预览发布与文档更新单独执行。只向确实在改本地网页、想找旧稿的人解释用途。

## 小红书正文

标题：网页改了几版，又想要之前那版

和AI改网页时，我经常想试另一种颜色、间距或布局，后来又想用之前的样子。

我把这个小工具收敛成了倒带 / Reprise：修改前说“保存这一稿，同时记住画面”。之后打开工作台，按图认出旧稿，取一份副本接着改。

它需要提前保存，不会自动记录所有修改。现在是源码Skill，由Agent检查并协助准备环境；这台Mac上的Codex已跑通两稿截图和旧稿恢复，其他机器和客户端还要分别验证。

如果你也遇过这种情况，你现在是怎么找旧稿的？我更想知道它具体省了哪一步，还是原来的办法更简单。

配图：本仓库当前版本的真实中英文工作台截图，标注“合成网页示例”。先展示两版颜色，再展示选回旧稿；不要把预览称为普遍验证或免环境安装。

## English introduction

I built Reprise for the moment when an AI-assisted webpage has gone through several changes and I want an earlier look back. Save a draft and its picture before editing, recognize it later, and recover a copy without overwriting the current project.

It is a source Skill, not automatic recording. The agent checks/reuses host tools and helps with missing dependencies. The macOS+Codex run completed two actual captures and byte-checked recovery; fresh-machine setup and other native clients remain unverified.

Preview: https://github.com/orocoa/Reprise/releases/tag/v0.8.0-rc.1
Docs: https://orocoa.github.io/Reprise/en/index.html
