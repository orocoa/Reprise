## Ask your agent to set it up

Download the complete Reprise-Skill.zip and give it to an agent with local file and command access:

**Install Reprise, check and reuse existing tools, help install missing dependencies through official methods and normal authorization, then open it.**

Retain scripts, assets and references; SKILL.md alone is insufficient. The agent verifies the actual Skill location, backs up an existing Skill and updates it without creating duplicate entries. New Codex installations use the official user or repository Skill locations; an existing recognized location can be reused.

Select Reprise through the client’s actual Skill entry and say “Open.” Opening does not save or import the current directory. An empty list is normal. A universal @ alias is not claimed.

## Save files and the picture

In a conversation where the website project is clear:

**Save this draft as “Before changing the colors”, including its screenshot.**

Check files saved and picture captured separately. Change the site, then save “After changing the colors” with its picture. Retry a missing picture against the same saved draft rather than saving identical files again.

Single-entry static HTML is the direct route. Build-based sites save first and present an install-and-run plan. Approved commands run in a separate copy. Setting up Reprise tools does not approve website scripts.
