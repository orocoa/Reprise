# Save a local webpage draft. Find it by its picture.

Reprise is an open-source Skill for people repeatedly editing local webpages with an AI agent or editor. Save the files and picture, recognize an earlier draft, and retrieve a copy to keep editing.

**Save before changing the site.** Reprise does not record every edit or recover drafts never saved. It is not an online URL bookmark service.
