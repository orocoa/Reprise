# 给本地网页留一稿，以后凭画面找回来

倒带 / Reprise 是给用 AI agent 或编辑器反复修改本地网页的人准备的开源 Skill。主动保存文件和画面，认出想找的旧稿，再取出副本继续改。

**先保存，再修改。** 它不自动记录每次编辑，无法找回从未保存的稿件；它也不是线上网址收藏夹。

<!-- RECOVERY_TEASER -->

## 从这里开始

1. [下载并接入 Skill](getting-started.md)。
2. 告诉 Agent：“本轮修改前后都帮我留稿。”
3. [按画面认稿并取回](find-compare-restore.md)。

## 当前范围

Reprise 0.8.1 保留网页留稿、版本图片和真实 Git 路线。本机 macOS + Codex 的安装、发现、两稿画面、工作台恢复、语言切换及重开已实际验证；新机器补齐依赖和其他客户端原生接入仍未验证。

入口明确、素材在本机的静态 HTML 可尝试直接出图；受支持 npm/Vite 项目先提出待批准的运行计划。文件和画面分别回报。

[隐私、依赖与常见问题](privacy-and-faq.md) · [GitHub 源码](https://github.com/orocoa/Reprise)

只保留「画面 / 版本关系」两种历史视图。画面显示每稿缩略图；版本关系使用固定紧凑路线，按真实分叉和合并浏览。宽图可横向滚动，缺图不会借用别版。通用功能扩展冻结，集中打磨当前流程。
