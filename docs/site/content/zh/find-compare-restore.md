# 按画面找旧稿，取出一份副本

打开 Reprise，在画廊中按画面、名称和时间认出想找的稿。选中它，查看这一稿自己的画面，再点“取出这一稿”。

默认使用原项目旁边的新文件夹，不需要手填尚不存在的完整路径。完成后打开结果位置，确认旧配色确实在，再继续修改副本。当前网页保持原样。

## 本次实际验证

本机 Codex 安装的源码 Skill 保存蓝色 A 与橙色 B，并生成各自真实图片。在工作台选回 A，切换英文并恢复到默认新目录；读取恢复文件确认等于 A，当前源文件仍等于 B。

## 缺图或运行不了时

没有图片也能取回已存文件，但不能称为已经完成按画面找回。恢复文件成功，不保证第三方服务或旧开发环境仍能运行。详见[常见问题](privacy-and-faq.md)。
