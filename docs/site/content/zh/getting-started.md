# 在 Codex 中接入 Reprise，保存第一稿

<!-- RECOVERY_RESOURCES -->

## 交给 Agent 接入

下载完整 Reprise-Skill.zip，交给有本机文件和命令能力的 Agent，说：

**帮我安装倒带 / Reprise，先检查复用现有环境，缺少的依赖按官方方法和正常授权安装，然后打开。**

保留包内脚本、assets 和参考资料，不能只复制 SKILL.md。Agent 核对实际技能目录，备份并更新已存在的技能，避免建立两个同名入口。Codex 新接入按官方用户或项目技能位置处理；本机已有识别目录可以复用。

选择客户端真正支持的 Reprise Skill 入口，说“打开”。只打开不会保存或导入当前目录；空列表正常。不把通用 @ 倒带 当作已实现的跨客户端语法。

## 留下第一稿和画面

在网页项目已经明确的对话里说：

**保存当前网页这一稿，叫“改颜色之前”，同时记住画面。**

Agent 分别回报文件是否保存、画面是否完成。修改后，再保存“改颜色之后”和它的画面。缺图时补同一稿的画面，不用重复保存相同文件。

静态 HTML 单入口最直接。需要构建的网页会先保存文件，再提出安装和运行计划；批准后在独立副本执行。准备 Reprise 工具环境不等于批准网页脚本。
