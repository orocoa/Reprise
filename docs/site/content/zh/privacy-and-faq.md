# Reprise：依赖、隐私与常见问题

## 需要安装哪些东西？

基础操作需要 Python3.9+ 与 Git，Python 核心只用标准库。自动截图另需 Node、Node 版 Playwright 与可用浏览器。当前 Playwright1.62.1 要求 Node20+；新装优先受支持的 Python 和 Node LTS。Agent 先检查复用，再按正常授权协助安装，不要求普通用户拼环境变量。

工具依赖安装在 Reprise 专用位置，网页自己的运行依赖在批准的独立副本中准备。两者都不写进受管源网页目录。

## 会自动保存每次修改吗？

不会。请在继续修改前主动留稿。未保存过的内容无法事后找回。

## 我的网页会被上传吗？

Reprise 核心的版本与工作台操作在本机完成。调用 Agent 时，工具输出或你让它读取的文件可能进入该 Agent 的模型上下文；不能把 Skill 当成数据绝不出设备的承诺。

版本库未加密，快照不能替代独立备份。截图可能含敏感内容，分享前自行确认。

## 截图失败，文件也丢了吗？

文件保存与画面采集是两个结果。已成功保存的文件保留，补同一稿的截图即可；不拿另一稿的图填补。

## Codex、WorkBuddy、TRAE 都验证了吗？

本机 macOS + Codex 的安装、技能发现、实际保存/出图和网页恢复已验证。新机器自动补齐环境、原生选择器/输入框及 WorkBuddy/TRAE 原生接入仍未验证。0.8.7 的 macOS/Python 3.9、Linux/Python 3.9 与 3.13 远端回归和全新包安装检查已通过；这不等于 WSL 桌面或其他客户端原生接入验证。

## 和 Git、编辑器历史有什么区别？

Reprise 把画面、保存的文件和取回副本连在同一条任务里。如果编辑器检查点、Git 或带截图的手动副本已经更省事，就没有必要额外安装它。

## MIT 开源、免费，是否等于没有成本？

源码采用 MIT；依赖各有许可。安装、磁盘空间、主动保存与维护仍有成本。Stars 是关注信号，不能代替实际完成或自然复用。
