# 2026-10-09 用户确认的界面与发行方向

从仓库打开 Reprise，一个工作台专注启动仓库。顶部和设置不提供项目切换或导入其他仓库；命令行继续支持从不同目录启动。已关联的同一项目历史存档只读展示，完整 SHA 去重，保留来源、真实父子关系及媒体归属。正式命令的显式 `--history` / `--history-catalog` 参数关联已有存档和原版本目录，不修改源 Git。

版本浏览保留「本次更新 / 版本预览 / 版本对比」。对比选择在标签页内；标题旁无框铅笔同时编辑名称与简介，更新说明旁铅笔只编辑更新内容。详细视图与 32px 紧凑视图使用同一组记录；紧凑视图保留分叉、名称与收藏标记。语言切换和运行管理位于右上角设置。收藏标记仍保存。运行配置与添加预览资料在设置内；已移除的详情工具栏不再重复这些入口。

## GitHub 发行包方向（规划）

- 基础版：Git 浏览、对比、运行与资料功能独立使用；默认不启用 AI，在设置中可自行配置 API 地址、模型和密钥。
- Codex 版：从 Codex 安装或启动时连接用户的 Codex。正式接入按官方 app-server 协议处理身份、模型选择、事件和取消，复用合法的登录状态或发起官方登录流程；不读取或复制桌面应用的私有凭证，也不因连接改变用户模型和权限设置。两个版本共用同一 Git / 版本 / 媒体核心。

2026-10-09 已将两组对话的最新共享界面整合进正式 web/，版本号为 0.3.0。基础 Python wheel 在本地构建验证；尚未上传或发布 GitHub 安装包。Codex provider 尚未实现，界面不会将其标为已连接。后续发行需完成接入、跨平台依赖、安装与升级验证。

依据：[OpenAI 官方 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)，2026-10-09 已查阅。官方协议提供 stdio 通信与 account/read、account/login/start、turn/start 等接口，适用于产品内部接入。
