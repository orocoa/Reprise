- Skill 主入口从 1441 个空白分词缩短到约 707 个，按需读取环境、截图和高级资料。旧候选说明不再混入默认参考。

## 验证与边界

本机完整 Python 与真实浏览器回归 582 项通过、无跳过；Node 契约 104 项通过。包括 1301 个真实 Git 对象的合成压力仓库，保留 1620 条有序父边、16 路并行和 320 个合并节点。wheel/源码包在源码外的 venv/user-site 四条安装路径通过；重复安装校验后复用同一运行时。

主附件 `Reprise-Skill.zip` SHA-256 为 `5b0e6e8400ea276344b295cf4204324d6dd133e35c7a8d5a5e94e95815a602cc`，从干净提交 `97a0073` 构建。用于发布门槛的 `91470de` 只增加隔离测试的翻译依赖；包内 103 个功能文件与它逐字节相同。[对应 CI](https://github.com/orocoa/Reprise/actions/runs/40222344017) 与发布附件清单分别记录测试和包身份。后续网站文档不改写此功能载荷。

本轮合成网页实测流程为首次只问一次截图选择、保存文件与准确画面、后续沿用偏好、按图选回原稿、取出新副本并读回核对。文件保存与图片状态分开报告；缺少默认浏览器时保存稿件仍保留，对同一个 SHA 重试截图。

画面一栏仍显示缩略图，版本关系保持固定紧凑路线。Git 图的全 SHA 与有序父边、跨视图定位、搜索与移动横向查看继续由回归约束；普通目录保存顺序不会冒充源 Git 分支。

本机测试和合成样本不代表新机器补依赖、其他客户端原生接入、独立用户采用或无限规模历史已验证。现有字体和历史兼容模块仍占用一部分包空间；整个历史仓库不称“零技术债”，维护主线与保留范围见 [架构](ARCHITECTURE.md) 和 [功能范围](FEATURES.md)。
